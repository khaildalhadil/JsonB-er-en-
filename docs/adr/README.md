# Architecture Decision Records (ADR)

Each ADR captures one significant, hard-to-reverse decision: the context, the
options weighed, the choice, and its consequences. ADRs are immutable once
**Accepted** — to change a decision, add a new ADR that supersedes it.

## Format

`NNNN-short-title.md`, sections: Status, Context, Decision drivers, Considered
options, Decision outcome, Consequences, Rejected option, References.
